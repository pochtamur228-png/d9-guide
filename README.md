# D9 Справочник — Telegram Mini App

Неофициальный справочник игрока DISTRICT 9 RP: кому и где продавать, работы, калькулятор золота, журнал дохода.
Весь код в одном файле `index.html`, сервер не нужен.

## Запуск в Telegram (≈10 минут)

Telegram открывает мини-приложение только по **HTTPS-ссылке**, поэтому файл нужно где-то разместить.

### 1. Разместить файл (GitHub Pages, бесплатно)
1. Зайди на github.com, создай репозиторий, например `d9-guide` (Public).
2. **Add file → Upload files** → загрузи `index.html` → **Commit**.
3. **Settings → Pages → Branch: main, / (root) → Save**.
4. Через 1–2 минуты появится ссылка вида `https://ТВОЙ_НИК.github.io/d9-guide/`. Открой её в браузере и проверь.

Альтернатива без GitHub: перетащи папку на app.netlify.com/drop, ссылка будет сразу.

### 2. Создать бота и подключить приложение
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username (должен оканчиваться на `bot`).
2. Кнопка меню: `/mybots` → твой бот → **Bot Settings → Menu Button → Configure menu button** → вставь ссылку из шага 1 → название кнопки, например «Справочник».
3. (По желанию) полноценный Mini App со ссылкой `t.me/ТВОЙ_БОТ/app`: `/newapp` → выбери бота → название, описание, картинка 640×360 → ссылка из шага 1 → короткое имя `app`.

Открой бота: слева от поля ввода появится кнопка, которая запускает справочник.

## Обновление данных
Все данные лежат в начале скрипта в `index.html`, в массивах `ITEMS` (кто что скупает) и `JOBS` (работы).
Поправил → загрузил файл в репозиторий заново → через минуту изменения в Telegram.

У каждой записи о скупщике есть пометка:
- `c:"wiki"` — подтверждено вики d9-rp.com;
- `c:"guess"` — предположение по названию скупщика. Когда проверишь в игре, поменяй на `"wiki"`.

## Где хранятся записи журнала
В Telegram CloudStorage: у каждого пользователя свои, на всех его устройствах. В обычном браузере — в localStorage.
